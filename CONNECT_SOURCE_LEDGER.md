# EchoPet Connect Source Ledger

This ledger records where parity rules come from and how they may be used in
firmware. It exists to stop placeholder values from becoming hidden truth.

## Confidence Levels

| Level | Meaning | Firmware use |
| --- | --- | --- |
| `A` | Official Bandai page/manual, or direct T-Echo-Lite hardware evidence. | May drive final code. |
| `B` | Cross-checked community/wiki/gameplay research with clear provenance. | May drive provisional code when official values are absent, but must remain traceable. |
| `C` | Single community claim, image chart, or uncited note. | Spec placeholder only; needs confirmation before final parity. |
| `D` | Current EchoPet implementation choice. | Not a source of truth; only a code-audit fact. |
